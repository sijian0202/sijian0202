大连理工大学工业设计在读，预计 2027 年毕业。关注 UI/UX、产品体验与 AI 辅助设计开发。

我希望把对用户与场景的理解转化为清晰的产品规则、可交互的界面和能够体验的作品。目前重点探索从用户研究、交互设计到前端实现的完整实践。

## 代表项目：我的匿名提问箱

一个围绕低压力表达与真诚回应展开的匿名问答项目。

- **设计问题**：如何区分匿名身份与内容可见范围，让提问、邀请回答和公开参与形成清晰的使用路径。
- **我的工作**：用户研究、UI 与交互设计、Figma 高保真原型，以及 AI 辅助的前端实现与迭代。
- **实现实践**：借助 Codex、Claude 将设计需求转化为可交互前端；通过 Mock 数据组织用户、问答、回复与关注关系。
- **协作边界**：参与从设计到上线的推进与维护；正式 App 由团队协作完成，在线演示使用独立的本地 Mock 数据。
